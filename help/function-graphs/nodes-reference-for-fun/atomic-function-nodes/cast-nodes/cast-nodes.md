# Nós de conversão

Os nós de conversão são usados para converter um nó de um tipo para outro tipo:

![](cast-nodes.resources/image2015-12-23-10-5-19.png)

## Como usar um nó cast?

Basta selecionar o nó de conversão que corresponde ao comprimento do nó que você deseja converter.
