## Descrição

Defina a metalidade do material de uma cena SDF.

Este valor pode ser recuperado para todas as formas SDF respingadas na saída *Metalidade do SDF* do [respingo de forma v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).

## Entradas

|                          |                             |
|--------------------------|-----------------------------|
| <b>Cena SDF</b> *Precisão decimal* | A cena do SDF de entrada. |
| <b>Metalidade</b> *Precisão decimal* | O valor de metalidade a ser definido. |
