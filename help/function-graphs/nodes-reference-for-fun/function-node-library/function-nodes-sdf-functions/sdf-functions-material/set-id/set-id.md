## Descrição

Defina a ID de material de uma cena SDF.

Este valor pode ser recuperado para todas as formas SDF espalhadas na saída *Splatter UVW* do [respingo de forma v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).

|                          |                        |
|--------------------------|------------------------|
| <b>Cena SDF</b> *Flutuante* | A cena do SDF de entrada. |
