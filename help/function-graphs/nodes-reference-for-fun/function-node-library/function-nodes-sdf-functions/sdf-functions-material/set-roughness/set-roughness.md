## Descrição

Defina a aspereza do material de uma cena de SDF.

Este valor pode ser recuperado para todas as formas de SDF espalhadas na saída de *aspereza do SDF* do [respingo de forma v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).
