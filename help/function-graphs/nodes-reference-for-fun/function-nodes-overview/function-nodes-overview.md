# Visão Geral dos Nós de Função

Esta página fornece uma visão geral completa de todos os nós de função e explica a codificação de cores usada para Tipos de Dados de Função. Você pode clicar em até páginas mais detalhadas com explicações adicionais.

Esses nós de função podem ser acessados clicando com o botão direito do mouse no editor de função de gráfico e escolhendo Elemento, pressionando a barra de espaço ou a tecla Tab em uma função ou por meio da seção Funções da Biblioteca.
