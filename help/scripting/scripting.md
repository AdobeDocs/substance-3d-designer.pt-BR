# Scripts

É possível controlar o aplicativo escrevendo plug-ins. Os plug-ins podem ser gravados na linguagem de script **Python** usando a versão **3.9**. A API Python fornecida no aplicativo permite acessar e usar muitos recursos diretamente dos scripts.

[Python](https://www.python.org/) é uma linguagem de script amplamente utilizada em muitos setores. Ele ajuda a criar ferramentas de automação, aceleração de fluxo de trabalho e gerenciamento de ativos, entre outros exemplos. A documentação da API pode ser acessada no menu principal com a ação **Ajuda** > **Documentação de script...**.
