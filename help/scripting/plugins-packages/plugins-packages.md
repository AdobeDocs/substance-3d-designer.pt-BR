# Pacotes de plug-ins

Pacotes Python são compatíveis com a criação de plug-ins para estender o aplicativo.

Eles são arquivos únicos com uma extensão sdplugin que contém tudo o que um plug-in precisa para funcionar. Para os desenvolvedores, os pacotes simplificam o compartilhamento e a distribuição de plug-ins aos usuários. Para os usuários, os pacotes são mais fáceis de instalar e gerenciar.

## Instalando pacotes de plug-ins

![Gerenciador de plug-ins](plugins-packages.resources/screenshot-from-2019-07-18-11-48-56.png "Gerenciador de plug-ins")

Os pacotes de plug-ins são instalados usando o <b>Gerenciador de plug-ins</b>, no menu <b>Ferramentas</b>:

1. Clique no botão <b>Instalar</b> e selecione o pacote de plug-ins a ser instalado
1. O plug-in será instalado no diretório inicial, no caminho padrão dos plug-ins de cada sistema operacional
1. Depois que o plug-in for instalado, ele será carregado automaticamente
