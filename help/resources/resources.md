# Recursos

Recursos são o conteúdo dos pacotes da Substance 3D Designer. Eles são usados para criar, gerar e visualizar material e dados de textura. Os recursos podem ser divididos em duas categorias principais: Recursos de gráfico e recursos não-gráfico. O método usado para criar ou importar Recursos difere entre tipos. Você pode ler a página dedicada sobre [Vinculação, Importação e Novos Recursos](../resources/importing-linking-and-new/importing-linking-and-new-resources.md) para entender melhor isso.

### RECURSOS NÃO GRÁFICOS

Recursos não gráficos são geralmente recursos auxiliares usados como dados adicionais em Gráficos ou para ajudar a visualizar resultados de Gráficos. Os seguintes tipos existem, cada um tem uma subpágina nesta seção dos documentos:

* [Bitmap](../resources/bitmap-resource/bitmap-resource.md)
* [Gráficos vetoriais (SVG)](../resources/vector-graphics-svg-res/vector-graphics-svg-resource.md)
