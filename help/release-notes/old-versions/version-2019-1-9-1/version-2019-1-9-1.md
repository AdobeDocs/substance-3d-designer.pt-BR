# Versão 2019.1 (9.1)

O **Substance Designer 2019.1** traz uma nova atualização para o Substance Engine para expandir ainda mais seus recursos, bem como novos filtros adicionais.

## Principais recursos

### Novo Nó de Processador de valor

![](version-2019-1-9-1.resources/version-2019-1-9-1-01.png)

O Substance Engine está agora na versão 7 e com ele traz o novo conceito de “Valores” dentro do gráfico de composição. Os valores são números e não texturas e, como tal, podem ser usados para realizar várias computações que podem ser compartilhadas entre nós através dos gráficos de função e gráficos de composição. O nó Processador de valor pode ler uma imagem de entrada e calcular um único valor de saída.

O nó do Processador de valor não está sozinho, para poder transmitir informações de trânsito pelo gráfico, foram feitas algumas alterações e adições:

* Os nós de saída podem ser alimentados diretamente com um valor e não necessariamente mais com uma imagem.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-02.png)
* Um novo **nó de entrada** chamado “Valor de Entrada” foi adicionado para que o gráfico possa consultar Valores.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-03.png)
* Os nós agora têm uma nova categoria abaixo de seus parâmetros chamada “Valores de entrada”, que pode ser usada para criar valores de entrada para o próprio nó.\
  Os valores de entrada podem ser referenciados dentro do gráfico de função por meio dos nós “Get”.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-04.png)

>[!NOTE]
>
> Assim como ocorre com todas as alterações de Substance Engine principal, o modo de compatibilidade é definido para a versão anterior (nova versão 6 por padrão). O que significa que nós incompatíveis terão uma borda amarela no gráfico. Para desativar/ocultar a borda amarela, basta alterar a versão do mecanismo nas configurações principais para a versão mais recente (por meio das Configurações do projeto):
> 
> ![](version-2019-1-9-1.resources/version-2019-1-9-1-05.png)

### Suporte ao Optix em Baker

![](version-2019-1-9-1.resources/version-2019-1-9-1-06.jpg)

A última atualização do Substance Designer introduziu DXR, que permite executar Rastreamento de raios do GPU em hardware compatível com RTX. Agora adicionamos suporte para o [Optix](https://developer.nvidia.com/optix), que permite o raytrace em outras GPUs da Nvidia, mesmo em Linux. Você pode esperar fazer bake pelo menos **5 vezes mais rápido** ao usar o Optix do que com o Rastreamento de raios normal da CPU.

Veja a lista de Baker afetados por essa alteração:

* Oclusão de ambiente da malha
* Normais Dobrados da Malha
* Thickness da malha

Se quiser desabilitar uma das duas infraestruturas, vá para as preferências principais (**Editar > Preferências**) e para as configurações de Preparadores:

![](version-2019-1-9-1.resources/version-2019-1-9-1-07.png)

>[!NOTE]
>
> Para acessar o recurso, **atualize para os seguintes drivers**:
> 
> * GPUs Nvidia 10XX e 20XX : **drivers 430.39** (compatíveis com DXR e Optix)
> * Nvidia 9XX e anteriores: **d** **drivers 419.67 ou 430.39** (os drivers 425.31 têm um problema com o Optix)
> 
> Observe que a DXR também está disponível nas GPUs [GeForce GTX 10xx](https://www.nvidia.com/en-us/geforce/news/geforce-gtx-dxr-ray-tracing-available-now/) (com drivers atualizados). A DXR também requer que o Windows esteja atualizado para funcionar, consulte [esta página](../../../best-practices/performance-optimization/performance-optimization-guidelines.md) para obter mais informações.

### Tempos de carregamento aprimorados para malhas OBJ

![](version-2019-1-9-1.resources/version-2019-1-9-1-08.jpg)

Nesta versão, aprimoramos nosso leitor de arquivos **obj** para reduzir o tempo de carregamento de malhas 3D. Os tempos de carregamento têm sido de velocidade até 3 vezes, especialmente para malhas que não têm UVs e normais definidos.

Essa melhoria de desempenho afetará os pães e a exibição 3D.

### Sistema de plug-ins Python aprimorado

![](version-2019-1-9-1.resources/version-2019-1-9-1-09.png)

Com esta atualização, adicionamos muitos recursos novos ao sistema de scripts:

* **Suporte ao Qt** : permite a compilação de UI personalizada que segue o mesmo estilo do resto do Aplicativo. A interface personalizada também pode ser integrada muito mais facilmente com esse novo sistema. (O Tkinter foi descontinuado.)
* **Funções de retorno de chamada**: agora é possível registrar funções de retorno de chamada. No momento, isso inclui apenas abrir e salvar arquivos, bem como a criação de elementos de interface. Retornos de chamada adicionais serão adicionados no futuro.
* **Threading**: os plug-ins agora podem criar threads para fazer processamento em segundo plano ou aguardar eventos do sistema operacional (como conexões de rede).

Para obter mais detalhes, observe o log de alterações da API que pode ser acessado por meio da entrada de menu **Ajuda > Documentação de API Python** dentro do Substance Designer.

### Novo conteúdo

Também temos alguns novos nós disponíveis na biblioteca padrão, alguns dos quais agora estão equipados com o novo nó Value processor:

* **Flood Fill Para Indexar**\
  Atribui um índice exclusivo a formas de um nó Flood Fill.\
  No exemplo abaixo, o nó Processador de pixels corresponde a Entrada de valor à forma e gera a saída de uma máscara como resultado.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-10.gif)
* **Non Uniform Directional Warp**\
  Aplica uma Distorção direcional na qual a intensidade e o ângulo são amostrados das entradas da imagem.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-11.gif)
* **Distorção Multidirecional**\
  Distorce a imagem de entrada várias vezes em várias direções.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-12.gif)
* **Extrusões na Altura**\
  Gera uma renderização ortográfica em 3D do Height fornecido. A visualização da câmera pode ser controlada com o gizmo de posição.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-13.gif)
* **Valor Mín./Máx.**\
  Retorna os valores de pixel mínimo e máximo da imagem de entrada.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-14.png)

>[!WARNING]
>
> Esta versão não é mais compatível com o CentOS 6.x. Para usar a versão mais recente do Substance Designer, atualize para o CentOS 7.x.
