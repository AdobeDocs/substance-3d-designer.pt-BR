# Polígono dos caminhos

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![Ícone de nó](paths-polygon.resources/paths-polygon-icon.png "Ícone de nó")

<b>Ferramentas de Spline e Caminho </b> > Ferramentas de Caminho

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Descrição

Gera uma primitiva (polígono) no formato Caminhos.

Use o nó [Transformação 2D de caminho](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-2d-transform/path-2d-transform.md) para posicionar o primitivo com precisão.

</td>
</tr>
</table>

<a name="outputs"></a>

## Saídas

|  |  |
|:---|:---|
| <b>Caminhos</b> <i>Cor</i> | Contém uma lista de um caminho codificado, descrevendo uma lista de segmentos codificados.<br>Não se destina a ser usado ou modificado diretamente. Procure por Caminhos para encontrar nós compatíveis. |

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Número de Lados</b> <i>Inteiro</i> | Dica: insira um número entre 100 e 1000 para gerar um círculo. |
