## Descrição

Gera uma primitiva (polígono) no formato Caminhos.

Use o nó [Transformação 2D de caminho](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-2d-transform/path-2d-transform.md) para posicionar o primitivo com precisão.

## Conectores de saída

<b>Caminhos</b> *Cor*\
Contém uma lista de um caminho codificado, descrevendo uma lista de segmentos codificados.\
Não se destina a ser usado nem modificado diretamente. Procure por Caminhos para encontrar nós compatíveis.

## Parâmetros

<b>Número de Lados</b> *Inteiro*\
Dica: insira um número entre 100 e 1000 para gerar um círculo.
