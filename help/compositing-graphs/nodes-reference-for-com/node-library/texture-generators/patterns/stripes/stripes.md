## Descrição

Gera um padrão de divisão em blocos gráficos, angulado. O padrão se ajusta para sempre garantir a continuidade.

## Parâmetros

* **Stripe**: *1 - 100* Define a quantidade de faixas. Desloca automaticamente o resultado para garantir a divisão em blocos gráficos.
* **Largura**: *0.0 - 1.0* Define a largura do Stripe.
* **Suavidade**: *0.0 - 1.0* Define a transição das bordas da faixa.
* **Shift**: *0 - 20* Inclina as faixas. Adiciona automaticamente mais faixas para garantir a divisão em blocos gráficos.
* **Alinhar**: *Bordas, Centro* Define o giro para Deslocamento.
* **Filtragem**: *False/True* Habilita a filtragem.
* **Expansão não quadrada**: *Falso/Verdadeiro*\
  Permite a compensação de esmagamento e alongamento com proporções não quadradas.
