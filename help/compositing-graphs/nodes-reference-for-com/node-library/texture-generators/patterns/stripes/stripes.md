## Descrição

Gera um padrão de divisão em blocos gráficos, angulado. O padrão se ajusta para sempre garantir a continuidade.

</td>
</tr>
</table>

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Stripe</b> <i>1 - 100</i> | Define a quantidade de faixas. Desloca automaticamente o resultado para garantir a divisão em blocos gráficos. |
| <b>Largura</b> <i>0.0 - 1.0</i> | Define a largura do Stripe. |
| <b>Suavidade</b> <i>0.0 - 1.0</i> | Define a transição das bordas da faixa. |
| <b>Turno</b> <i>0 - 20</i> | Inclina as faixas. Adiciona automaticamente mais faixas para garantir a divisão em blocos gráficos. |
| <b>Alinhar</b> <i>Bordas, Centro</i> | Define a tabela dinâmica para Deslocamento. |
| <b>Filtragem</b> <i>Falso/Verdadeiro</i> | Ativa a filtragem. |
| <b>Expansão não quadrada</b> <i>Falso/Verdadeiro</i> | Permite a compensação de esmagamento e alongamento com proporções não quadradas. |
