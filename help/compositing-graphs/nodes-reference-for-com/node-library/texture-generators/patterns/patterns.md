# Padrões

Padrões são gráficos artificiais que parecem artificiais. Eles seguem principalmente regras para sua colocação, mas a variação aleatória pode ser introduzida na maior parte do tempo.

Elas são úteis quando você deseja um padrão regular como base, como tijolos, ladrilhos, padrões tecidos etc.

Quase todos os padrões são ladrilhados perfeitamente e são independentes da resolução, o que significa que você pode redimensioná-los sem perda de qualidade.

Use a <b>lista de navegação à esquerda</b> para procurar todos os nós em Padrões.
