## Descrição

Renderiza um cubo 3D em tons de cinza com sombreamento que também serve como profundidade de tela. O cubo resultante tem bordas super nítidas e nítidas quando usado com profundidades de bits de alta precisão. Muito interessante e útil!

</td>
</tr>
</table>

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Deslocamento de orientação</b> | Permite uma rotação em X e Y semelhante a 3D do cubo. Também pode ser feito manipulando o pequeno ponto na visualização 2D (conforme mostrado no exemplo abaixo) |
| <b>Tamanho</b> <i>0.0 - 1.0</i> | Permite o redimensionamento não uniforme do cubo. |
| <b>Escala</b> <i>0.0 - 1.0</i> | Redimensiona o cubo inteiro uniformemente. |
| <b>Expansão não quadrada</b> <i>Falso/Verdadeiro</i> | Permite a compensação de esmagamento e alongamento com proporções não quadradas. |
