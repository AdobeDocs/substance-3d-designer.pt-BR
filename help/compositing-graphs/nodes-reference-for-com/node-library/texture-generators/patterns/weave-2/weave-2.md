## Descrição

Gera um padrão de tecelagem simples. Tem controles para aleatoriedade. Na desordem máxima, isso pode até mesmo ser usado como um ruído.

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Divisão em blocos gráficos</b> <i>1 - 16</i> | Define a quantidade de vezes que o resultado deve ser colocado lado a lado. |
| <b>Desordem</b> <i>0.0 - 100.0</i> | Salta ao redor dos pontos da trama para introduzir variação. |
| <b>Girar 45 Graus</b> <i>Falso/Verdadeiro</i> | Gira para o ângulo predefinido. |
| <b>Expansão não quadrada</b> <i>Falso/Verdadeiro</i> | Permite a compensação de esmagamento e alongamento com proporções não quadradas. |
