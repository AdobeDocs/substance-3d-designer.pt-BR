## Descrição

Este é um nó interessante que gera um padrão fluido fluido fluindo ou caindo. É um dos ruídos mais complexos, com alguns parâmetros.

Esse ruído preenche um nicho específico: pode ser útil para gerar chuva, vazamentos ou qualquer tipo de fluido sob efeitos de gravidade.

</td>

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Escala</b> <i>1 - 8</i> | Define a escala global do efeito. |
| <b>Desordem</b> <i>0.0 - 1.0</i> | Muda a fase do ruído para introduzir uma pequena variação. |
| <b>Intensidade de distorção</b> <i>0.0 - 1.0</i> |  |
| <b>Tamanho do padrão</b> <i>0.0 - 1.0</i> |  |
| <b>Expansão não quadrada</b> <i>Falso/Verdadeiro</i> | Permite a compensação de esmagamento e alongamento com proporções não quadradas. |
