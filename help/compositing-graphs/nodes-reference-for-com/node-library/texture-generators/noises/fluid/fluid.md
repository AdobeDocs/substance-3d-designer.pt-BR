## Descrição

Este é um nó interessante que gera um padrão fluido fluido fluindo ou caindo. É um dos ruídos mais complexos, com alguns parâmetros.

Esse ruído preenche um nicho específico: pode ser útil para gerar chuva, vazamentos ou qualquer tipo de fluido sob efeitos de gravidade.

## Parâmetros

* **Escala**: *1 - 8*\
  Define a escala global do efeito.
* **Desordem**: *0.0 - 1.0*\
  Muda a fase do ruído para introduzir uma pequena variação.
* **Intensidade de distorção**: *0.0 - 1.0*
* **Tamanho do Padrão**: *0.0 - 1.0*
* **Expansão não quadrada**: *Falso/Verdadeiro*\
  Permite a compensação de esmagamento e alongamento com proporções não quadradas.
