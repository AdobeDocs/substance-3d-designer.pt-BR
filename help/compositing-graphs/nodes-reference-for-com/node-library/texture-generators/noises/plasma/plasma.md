## Descrição

Isso gera uma variante um pouco diferente de [Ruído gaussiano](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/gaussian-noise/gaussian-noise.md), com faixas escuras mais longas como vales. Ele tem um controle de distância semelhante para escala, que mantém a divisão em blocos gráficos.

## Parâmetros

* **Escala**: *1 - 128*\
  Define a escala global do efeito.
* **Desordem**: *0.0 - 1.0*\
  Muda a fase do ruído para introduzir uma pequena variação.
* **Expansão não quadrada**: *Falso/Verdadeiro*\
  Permite a compensação de esmagamento e alongamento com proporções não quadradas.
