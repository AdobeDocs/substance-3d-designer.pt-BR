<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Escala</b> <i>1 - 8</i> | Define a escala global do efeito. |
| <b>Escala de Ondas</b> <i>0.0 - 1.0</i> | Modifica a escala das ondas, maior significa menos repetições. |
| <b>Rotação de Ondas</b> <i>0.0 - 1.0</i> | Torce mais as ondas. Esse valor deve ser mantido baixo, pois os resultados podem ser extremos. |
| <b>Expansão não quadrada</b> <i>Falso/Verdadeiro</i> | Permite a compensação de esmagamento e alongamento com proporções não quadradas. |
