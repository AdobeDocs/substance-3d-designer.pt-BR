## Descrição

Isso gera um tipo ondulado de ruído semelhante a pelo.

## Parâmetros

* **Escala**: *1 - 8*\
  Define a escala global do efeito.
* **Escala de Ondas**: *0.0 - 1.0*\
  Modifica a escala das ondas, maior significa menos repetições.
* **Rotação de Ondas**: *0.0 - 1.0*\
  Torce mais as ondas. Esse valor deve ser mantido baixo, pois os resultados podem ser extremos.
* **Expansão não quadrada**: *Falso/Verdadeiro*\
  Permite a compensação de esmagamento e alongamento com proporções não quadradas.
