## Descrição

O nó **Galvanic Small** do Desgaste gera um mapa de desgaste semelhante ao padrão de aço densamente galvanizado.

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Saldo</b> <i>Precisão decimal</i> | Ajusta o equilíbrio entre valores escuros e brilhantes. |
| <b>Contraste</b> <i>Precisão decimal</i> | Ajusta o contraste da imagem. |
| <b>Inverter</b> <i>Booleano</i> | Inverte a saída da imagem, usando uma operação `1-x`. |
| <b>Expansão não quadrada</b> <i>Booleano</i> | Permite a compensação de esmagamento e alongamento com proporções não quadradas. |
| <b>Avançado</b> |  |
| <b>Nitidez</b> <i>Precisão decimal</i> | Ajusta a nitidez das formas galvanizadas. |
| <b>Dirt</b> <i>Precisão decimal</i> | Ajusta a opacidade da sobreposição da dirt. |
| <b>Micro Distorção</b> <i>Flutuante</i> | Ajusta a intensidade do efeito de distorção de alta frequência. |
