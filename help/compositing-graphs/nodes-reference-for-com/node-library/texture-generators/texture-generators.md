# Geradores de textura

Os geradores de textura são nós que não exigem nenhuma entrada: eles geram imagens completamente do zero. Você pode pensar em &#39;geradores de textura&#39; como outra palavra para &#39;procedimentos&#39;.

Eles são divididos em duas categorias:

* [Ruídos](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  Ruídos são os verdadeiros gráficos processuais, formas aleatórias e pixels, como os bem conhecidos ruídos de Perlin e Clouds.
* [Padrões](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  Padrões são na maioria das vezes formas que parecem feitas pelo homem, com muitos controles adicionais para aleatorizá-los.
