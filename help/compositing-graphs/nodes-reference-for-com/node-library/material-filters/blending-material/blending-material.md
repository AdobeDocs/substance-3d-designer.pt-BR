# Mesclagem (material)

A categoria Mesclagem é uma das categorias de materiais multicanais mais importantes. Contém nós destinados a combinar, comutar e misturar materiais que consistem em múltiplas saídas simultâneas.

Esses nós podem economizar uma enorme quantidade de trabalho, mas certifique-se de entender completamente os [Modos de Criação de Link](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) para utilizá-los corretamente.

Os seguintes nós são bons para começar:

* [Mesclagem de vários materiais](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/multi-material-blend/multi-material-blend.md)
* [Combinar de ajuste de material](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-adjustment-blend/material-adjustment-blend.md)
