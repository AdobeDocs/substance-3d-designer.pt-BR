# Utilitários PBR

Esta categoria contém nós auxiliares para trabalhar com materiais PBR. Destina-se ao uso com fluxos de trabalho de PBR de Specular reluzente e aspereza metálica. Todos os nós são destinados a materiais multicanal, e os canais podem ser (des)ativados para suportar um ou ambos os workflows.

Os seguintes nós são especialmente úteis:
