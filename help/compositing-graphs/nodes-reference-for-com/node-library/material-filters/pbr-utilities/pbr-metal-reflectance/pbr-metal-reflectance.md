## Descrição

Este é um nó auxiliar Predefinição rápida para retornar as cores de reflexo corretas para alguns metais **puros** predefinidos. Ele pode ser usado na cor de base para o modelo Metálico ou no canal de Specular para o modelo Specular/Textura reluzente.

Esse nó é útil quando você deseja um ponto de partida para um metal puro e permite evitar a separação de cores de um gráfico.
