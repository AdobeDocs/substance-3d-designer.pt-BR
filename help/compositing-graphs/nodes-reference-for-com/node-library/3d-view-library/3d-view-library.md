# Visualização 3D (biblioteca)

A categoria Exibição 3D contém apenas nós relacionados a HDRIs esféricos projetados, seja aqueles usados na Exibição 3D do Substance 3D Designer ou para exportar para outros aplicativos, como o Substance 3D Painter.

Existem duas subcategorias:

* **Ambientes HDRI**: nenhuma documentação está disponível, pois são apenas imagens destinadas a exibição na Exibição 3D, sem parâmetros adicionais.
* **Ferramenta HDRI**: nós de ferramenta para criar e editar imagens HDRI esféricas. Introduzido no SD 2019.2.
