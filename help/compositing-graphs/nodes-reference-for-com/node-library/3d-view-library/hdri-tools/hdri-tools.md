# HDRI Tools

As Ferramentas HDRI são nós destinados a manipular e criar imagens HDRI. Especificamente, isso significa que esses nós têm funcionalidade para trabalhar e gerar valores de Intervalo dinâmico corretos, bem como nós que levam em conta e compensam o mapeamento de projeção esférica.
