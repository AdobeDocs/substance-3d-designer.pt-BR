## Descrição

Mescle várias exposições fotográficas para criar uma imagem de Intervalo dinâmico. A primeira entrada é a imagem mais subexposta.

## Entradas

* **Entrada 1-**&#x200B;**&#x200B; 16**: *Entrada de cores*Imagens de entrada. O valor disponível depende do parâmetro.

## Parâmetros

* **Entradas**: *2 - 16*\
  Define a quantidade de entradas disponíveis.
* **Delta De Exposição (EV)**: *0.0 - 4.0*\
  Define a diferença na exposição para interpretar entre imagens.
* **Ponto branco**: *0.0 - 13.0* Defina o ponto branco para executar alguns ajustes no resultado final.
