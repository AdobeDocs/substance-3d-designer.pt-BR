# Biblioteca de nós

Além dos [nós atômicos](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md), o Designer também vem com uma biblioteca de [Instâncias de gráfico](../../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md) predefinidas, divididas em muitas categorias. Existem mais de 200 diferentes, alguns são úteis com muita frequência, alguns são destinados a casos de uso muito específicos.Esta área da documentação documenta e explica todos os nós Biblioteca e fornece ponteiros e dicas sobre quais nós são bons para começar.

O painel Biblioteca do Designer exibe mais categorias do que as que documentamos atualmente, mais notavelmente os nós MDL estão ausentes, elas podem ser adicionadas no futuro.
