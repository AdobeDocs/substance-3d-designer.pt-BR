## Parâmetros

|  |  |
|:---|:---|
| <b>Amostras</b> <i>1 - 128</i> | Defina a qualidade do efeito de desfoque. |
| <b>Ângulo</b> <i>0.0 - 0.5</i> | Defina a intensidade de “giro” do efeito. |
| <b>Posição Central</b> | Defina o ponto central do efeito. |
