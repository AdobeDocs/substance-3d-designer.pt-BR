# Desfoques

A categoria Desfoques se expande no [nó padrão de Desfoque de Caixa Atômica](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md). Ele contém Desfoques mais avançados e de melhor qualidade que podem ser usados várias vezes.

Lembre-se de que cada nó de Desfoque da biblioteca apresenta uma versão em Tons de cinza e Colorida. Tente usar a versão apropriada para sua entrada.

Alguns bons desfoques para verificar:

* [Desfoque HQ](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blur-hq/blur-hq.md)
