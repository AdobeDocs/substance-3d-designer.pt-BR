## Descrição

Um nó de conversão avançado Height-para-normal que faz uso de unidades do mundo real durante a conversão.

Útil para quando você conhece as dimensões do mapa de altura de origem e deseja executar a conversão mais precisa, como ao trabalhar com material digitalizado.

## Parâmetros

* **Tamanho da Superfície (cm)**: *0.0 - 1000.0* Dimension do Heightmap de entrada.
* **Profundidade de Height (cm)**: *0.0 - 100.0* profundidade máxima de detalhes de Heightmap.
* **Formato Normal**: *OpenGL, DirectX*\
  Alterna entre diferentes formatos de Mapas Normais (inverte o canal verde).
* **Amostragem**: *Padrão, Sobel* Alterna entre dois modos de amostragem determinando a precisão.
