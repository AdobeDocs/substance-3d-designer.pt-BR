# Ajustes

Esta é uma das principais categorias de filtro, com nós destinados a ajustar os valores e intervalos de entradas de várias maneiras. A maioria dos nós é uma maneira avançada e expandida de usar nós [Níveis](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) e [Mesclar](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blend/blend.md), e tem como objetivo criar atalhos mais inteligentes para determinadas operações.

Use a <b>lista de navegação à esquerda</b> para procurar todos os nós em Ajustes.
