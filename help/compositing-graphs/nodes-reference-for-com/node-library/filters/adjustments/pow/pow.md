## Descrição

Potencializa a entrada por um expoente especificado. Semelhante a ajustar o [Ponto médio](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)dos Níveis, mas em um pacote mais simples. Útil também para quando você deseja executar uma operação matemática exata de energia.

Importante: certifique-se de usar a versão correta, dependendo se você possui uma entrada Colorida ou em Escala de cinza!

</td>

## Parâmetros

|  |  |
|:---|:---|
| <b>expoente</b> <i>0.0 - 10.0</i> | Expoente pelo qual alimentar a entrada. |
