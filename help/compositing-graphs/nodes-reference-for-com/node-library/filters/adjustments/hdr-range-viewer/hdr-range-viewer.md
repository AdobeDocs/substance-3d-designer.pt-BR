## Parâmetros

|  |  |
|:---|:---|
| <b>Intervalo Mínimo</b> <i>-2.0 - 0.0</i> | Intervalo mínimo para iniciar o realce. |
| <b>Intervalo Máximo</b> <i>1.0 - 3.0</i> | Intervalo máximo para realçar até. |
