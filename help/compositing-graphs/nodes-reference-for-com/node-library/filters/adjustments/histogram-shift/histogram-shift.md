# Deslocamento do histograma

<table>

<td width="33.33%" style="border: 0;" valign="top">

<b>Entrada:</b> Filtros > Ajustes

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Descrição

Alterna completamente todo o intervalo da imagem, envolvendo-o ao atingir os limites do intervalo.

[Clique aqui para assistir a um vídeo do Substance Academy sobre Histograma Shift.](https://youtu.be/p9wcmJBFyGA?t=492)

</td>
</tr>
</table>

<a name="parameters"></a>

## Parâmetros

|  |  |
|:---|:---|
| <b>Posição</b> <i>0.0 - 1.0</i> | Por quanto deslocar a entrada. 1.0 é uma rotação completa e é igual a 0.0. |
