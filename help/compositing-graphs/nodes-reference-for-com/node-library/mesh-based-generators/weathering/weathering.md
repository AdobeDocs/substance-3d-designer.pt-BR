# Ação do tempo

Os nós de intemperismo levam os [Geradores de máscaras](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/mask-generators.md) um passo adiante: eles fazem um efeito de intemperismo material completo com base em parâmetros e mapas baked. O conceito é muito semelhante ao de [Materiais inteligentes](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/features/smart-materials-and-masks) em Substance Painter.

Você precisa ter um ou mais mapas baked para obter um resultado completo desses nós.

Lembre-se de que, como esses nós oferecem efeitos completos e abrangentes, seu uso é limitado a apenas alguns casos. No entanto, elas também podem ser uma boa base para aprender como esses efeitos complexos são criados. Arraste os nós da biblioteca para o Explorer ou clique com o botão direito do mouse e escolha “Abrir referência” em um nó colocado no gráfico.
