# Geradores de máscara

Esta categoria contém uma seleção de nós geradores de máscaras em preto e branco. Com base em informações do mapa baked, eles geram máscaras que podem ser usadas para mesclar materiais e outros efeitos. Estes nós são semelhantes ao [Máscara inteligente](https://experienceleague.adobe.com/pt-br/docs/substance-3d-painter/using/features/smart-materials-and-masks) e ao [Geradores](https://experienceleague.adobe.com/pt-br/docs/substance-3d-painter/using/content/creating-custom-effects/generators) no Substance Painter.

Todos esses nós exigem [mapas baked](../../../../../bakers/bakers.md), pois sem [mapas baked](../../../../../bakers/bakers.md) não haverá muito resultado.

O principal uso pretendido é usar esses geradores de máscara com [materiais de vários canais](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md). Depois que uma máscara é gerada, ela é usada como máscara de mesclagem para [Combinar de material](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-blend/material-blend.md).

Alguns nós interessantes nesta categoria são:

* [Ferrugem de gotejamento](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/dripping-rust/dripping-rust.md)
* [Danos na borda](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/edge-damages/edge-damages.md)
* [De baixo para cima](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/bottom-to-top/bottom-to-top.md)
* [Construtor de máscaras](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/mask-builder/mask-builder.md)
