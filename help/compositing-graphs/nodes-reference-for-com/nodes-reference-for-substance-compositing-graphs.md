# Referência de nós para gráficos do Substance

Como o Substance 3D Designer é um software de texturização baseado em nós, há muitos nós diferentes à sua disposição. Esta seção tem como objetivo explicar os diferentes tipos e documentar todos os nós fornecidos com o software.

O que chamamos de “nó” dentro do SD, pode ser dividido em 2 grupos principais:

* [Os nós atômicos](../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md), os principais blocos de construção de qualquer gráfico.
* [As instâncias de gráfico](../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md), nós compostos, dos quais uma grande seleção de conteúdo pré-criado está disponível na [biblioteca de nós](../../compositing-graphs/nodes-reference-for-com/node-library/node-library.md)
