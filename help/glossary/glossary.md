# Saiba mais sobre os termos e conceitos usados no Designer.

## #

|  |  |
| --- | --- |
| <b><span id="three-d-scene" data-preserve-html="true"></span>Cena 3D</b> | Uma coleção de objetos e dados envolvidos na representação e animação de uma visualização de espaço 3D:<ul data-preserve-html="true"> <li data-preserve-html="true">[Malhas](#mesh)</li> <li data-preserve-html="true">[Materiais](#material)</li> <li data-preserve-html="true">Câmeras</li> <li data-preserve-html="true">Luzes</li> <li data-preserve-html="true">Animação</li> <li data-preserve-html="true">Simulações</li> <li data-preserve-html="true">...</li> </ul>Os [formatos de arquivo populares](https://www.adobe.com/products/substance3d/discover/3d-files-formats.html) para armazenar cenas 3D incluem o [USD](#usd) da Pixar e o FBX da Autodesk. Nem todos os formatos de arquivo são compatíveis com todos esses componentes |

## A

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="alpha" data-preserve-html="true"></span>canal de Alpha</b> | O quarto canal de uma imagem colorida, geralmente usado para descrever a opacidade. |
| <b><span id="ambient-occlusion" data-preserve-html="true"></span>oclusão de ambiente</b> | A atenuação da luz ambiente em superfícies menos expostas e, portanto, mais difíceis de alcançar. |
| <b><span id="anisotropy" data-preserve-html="true"></span>Anisotropia</b> | A propriedade de ser dependente da direção. Em outras palavras, fornecer um resultado diferente quando medido ou observado em um eixo diferente.<br><br>Os materiais anisotrópicos têm uma aparência diferente dependendo de onde são analisados e os filtros anisotrópicos não são aplicados uniformemente em todas as direções. |
| <b><span id="aov" data-preserve-html="true"></span>AOV</b> | A AOV (Variável de Saída Arbitrária) é um termo usado na [renderização](#rendering) para descrever canais de dados adicionais que podem ser exportados de uma renderização, como profundidade, normais ou dados personalizados. |
| <b><span id="api" data-preserve-html="true"></span>API</b> | Uma Interface de Programação de Aplicativo (API) é um conjunto de funções e procedimentos que permite aos usuários acessar as funções e procedimentos de outro aplicativo do programa.<br><br>Uma API fornece uma camada controlada e segura entre o usuário e um programa. Ele também pode usar outra linguagem de programação para tornar esse programa mais fácil de interagir e mais amplamente acessível.O <br><br>Designer oferece uma [API Python](../scripting/scripting.md) que fornece acesso fácil a uma ampla variedade de recursos para manipular dados, criar ferramentas personalizadas e acelerar fluxos de trabalho. |
| <b><span id="atomic-node" data-preserve-html="true"></span>Nó atômico</b> | Os blocos de construção fundamentais do gráfico. Todos os [nós de instância](#instance-node) podem ser divididos em gráficos de nós atômicos.<br>Cada tipo de gráfico tem seu próprio conjunto de nós atômicos. |

## B

|                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="baking" data-preserve-html="true"></span>Preparação</b> | O processo de calcular informações de um modelo 3D e armazenar os resultados em uma [textura](#texture). Os dados são colocados na textura de acordo com os [UVs](#uv) do modelo. |
| <b><span id="base-color" data-preserve-html="true"></span>Cor base</b> (Albedo) | Um canal de um [material](#material) definido usando o modelo de aspereza metálica PBR [sombreamento](#shader).<br>A cor base especifica a cor de uma superfície sem informações de iluminação.<br><br>Não deve ser confundido com [Difuso](#diffuse). |
| <b><span id="base-parameter" data-preserve-html="true"></span>Parâmetro base</b> | Um parâmetro comum a todos os nós em um gráfico de Substance que calcula um [bitmap](#bitmap).<br><br>Incluem aspectos principais do bitmap, como sua resolução ([Tamanho de saída](#output-size)) e [profundidade de bits](#bit-depth) ([Formato de saída](#output-format)), ou como o bitmap é calculado, como o modo [lado a lado](#tiling).<br><br>Os parâmetros base geralmente são [herdados](#inheritance) de outros nós upstream ou do gráfico que hospeda o nó. |
| <b><span id="bilinear-filtering" data-preserve-html="true"></span>Filtragem bilinear</b> | Um processo de interpolação usado em imagens por computador quando uma [amostra de textura](#texture-sampling) não é executada exatamente no centro de um pixel.<br><br>Por exemplo, isso pode ocorrer quando uma imagem é ampliada. |
| <b><span id="bit-depth" data-preserve-html="true"></span>Profundidade de bits</b> | O número de bits usados para armazenar o valor de um pixel em uma textura. Profundidades de bits mais altas permitem a codificação de mais valores, resultando em gradientes mais suaves.<br><br>profundidades de bits diferentes estão disponíveis dependendo do tipo do valor: - Os valores inteiros podem ser codificados usando 8 bits (0 a 255) ou 16 bits (0 a 65.535). - Os valores de ponto flutuante podem ser codificados usando-se 16 bits (+32767.9999 a -32768.0 ) ou 32 bits (-3.4E+38 a +3.4E+38)<br><br>As imagens de intervalo dinâmico baixo usam valores inteiros para codificar etapas de 0 a 1. As imagens de intervalo dinâmico usam valores de ponto flutuante para codificar valores numéricos brutos.<br><br>Em gráficos de Substance, a profundidade de bits é controlada pelo parâmetro [Formato de Saída](#output-format). |
| <b><span id="bitmap" data-preserve-html="true"></span>Bitmap</b> | Uma imagem digital. Dois tipos de imagens são mais comuns:<ul data-preserve-html="true"> <li data-preserve-html="true">As imagens em tons de cinza têm apenas um canal: luminância (L);</li> <li data-preserve-html="true">As imagens coloridas têm três canais: vermelho, verde e azul (RGB). Um quarto pode estar presente: [alfa](#alpha) (A), que é frequentemente usado para opacidade. As imagens coloridas no Designer são sempre RGBA.</li> </ul>  Os bitmaps podem ser vistos como grades de valores. Cada célula dessa grade é um pixel, que é a abreviação de “elemento de imagem”. Um pixel armazena um valor por canal. O tipo desse valor depende da [profundidade de bits](#bit-depth) do bitmap. |

## C

|                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="cache" data-preserve-html="true"></span>Cache</b> (Memória) | Uma coleção de dados - ex. [parâmetros base](#base-parameter) do nó e imagens de saída - armazenados na memória para serem reutilizados.<br><br>O cache acelera muito os cálculos do gráfico, permitindo que o [Substance Engine](#substance-engine) recalcule apenas as partes de um gráfico que foram alteradas. Ao ajustar as conexões e os parâmetros do nó, todos os nós que o precedem não são afetados por essas alterações, portanto, não precisam ser [avaliados](#evaluation) novamente para atualizar o gráfico. Seu cache é usado no lugar.<br><br>O cache pode ocupar uma parte significativa da memória ao trabalhar com altas resoluções e profundidades de bits em gráficos grandes. |
| <b><span id="channel-packing" data-preserve-html="true"></span>embalagem de canal</b> | Uma técnica de otimização em que imagens separadas são compactadas nos canais RGB(A) de uma imagem colorida única.<br><br>Por exemplo, uma textura RMA é um mapa de [aspereza](#roughness) (R), um mapa de metalidade (M) e um mapa de [oclusão ambiente](#ambient-occlusion) (A), todos empacotados em uma textura de cor única.<br><br>Outra técnica comum é a embalagem de uma textura em tons de cinza no canal azul de um [mapa normal](#normal-map), pois o canal azul, isto é, o componente &#39;Acima&#39; do vetor normal, pode ser recalculado no tempo de execução.<br><br>O nó [mesclagem de RGBA](../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md) é útil para implementar essa técnica. |
| <b><span id="color-space" data-preserve-html="true"></span>Espaço de cores</b> | Uma definição de como um intervalo de cores é representado.<br>A codificação e decodificação digital de uma cor específica requer essa definição para que os números usados sejam compreendidos.<br><br>Um arquivo de imagem armazena valores de cores usando um espaço de cores especificado, para que essas cores possam ser reproduzidas fielmente em uma exibição que ofereça suporte a esse espaço de cores. Um monitor tem recursos de reprodução de cores específicos que lhe permitem oferecer suporte total ou parcial a um determinado espaço de cores.<br><br>Dados brutos - Por exemplo: um [mapa normal](#normal-map) - sempre é codificado e decodificado em um espaço de cores Linear porque essas cores não devem ser visualizadas e nenhuma transformação deve ser aplicada a esses dados.<br><br>sRGB é um espaço de cores com suporte amplo. Outros espaços de cores populares incluem Adobe RGB, Rec. 2100 e ProPhoto RGB. |
| <b><span id="cooking" data-preserve-html="true"></span>Cozinhar</b> (<span id="compilation" data-preserve-html="true"></span>Compilação) | O processo de tradução de dados para outro idioma para que possam ser executados de forma rápida e eficiente.<br>Computar o resultado de um gráfico de Substance requer compilá-lo primeiro. A compilação faz parte do processo de [avaliação](#evaluation) do gráfico.<br><br>Esta compilação é executada em um gráfico nivelado, o que significa que todos os [nós de instância](#instance-node) são &#39;substituídos&#39; por seus gráficos de origem para que um gráfico maior permaneça, e esse gráfico seja o que for compilado.<br><br>Um gráfico compilado não é editável. O parâmetro exposto permanecerá disponível se for [dinâmico](#dynamic-parameter), enquanto os parâmetros [estáticos](#static-parameter) estiverem bloqueados e ocultos. |
| <b><span id="culling"></span>Selecionando</b> | Uma técnica de otimização para [renderização](#rendering) [cenas 3D](#three-d-scene) que remove a geometria dos cálculos de uma renderização quando não está visível.<br><br>Isso pode incluir objetos ou polígonos fora do fruto da câmera (*eliminação de afluxo*), voltados para o lado oposto da câmera (*eliminação de rosto posterior*) ou completamente ocultos por outros objetos opacos (*eliminação de oclusão*). |

## D

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="dependency" data-preserve-html="true"></span>Dependência</b> | Um arquivo A que é usado por outro arquivo B de forma que o arquivo B não funcione conforme o esperado quando o arquivo A está ausente.<br><br>Uma dependência de um [pacote](#package) pode ser outro pacote porque faz referência a um gráfico dentro dele, um arquivo de imagem, uma fonte etc.<br><br>Um pacote armazena o caminho para sua dependência e um aviso será emitido se a dependência não for encontrada nesse caminho. Dependências ausentes também podem resultar em [nós de instância fantasma](#ghost-instance-node) em um gráfico. |
| <b><span id="diffuse" data-preserve-html="true"></span>Difusa</b> | Um canal de um [material](#material) definido usando o modelo de Textura reluzente do Specular PBR [sombreamento](#shader). Difusa especifica a cor de uma superfície quando iluminada.<br><br>Não deve ser confundido com [Cor base (Albedo)](#base-color). |
| <b><span id="directx" data-preserve-html="true"></span>DirectX</b> | Uma coleção de APIs para manipulação de conteúdo multimídia. A API 3D, Direct3D, é amplamente usada no desenvolvimento de jogos de vídeo e em outras indústrias 3D.<br><br>A Direct3D coloca a origem de uma textura, isto é, sua coordenada (0, 0), no *canto superior esquerdo*, (Y-baixo), enquanto a API [OpenGL](#opengl) a coloca no *canto inferior esquerdo* (Y-acima).<br><br>Isso significa que um [mapa normal](#normal-map) de DirectX tem um *canal verde invertido* comparado ao OpenGL. De fato, o canal verde hospeda a coordenada Y dos vetores normais. |
| <b><span id="displacement" data-preserve-html="true"></span>Deslocamento</b> | O processo de mover os [vértices](#vertex) de um modelo 3D, geralmente ao longo do [normal](#normal).O <br><br>Deslocamento é frequentemente usado em combinação com o [mosaico](#tessellation) e os [mapas normais](#normal-map) para modelar detalhes mais finos em uma superfície. |
| <b><span id="dynamic-parameter" data-preserve-html="true"></span>Parâmetro dinâmico</b> | Um parâmetro cujo valor pode ser alterado. Em outras palavras, qualquer parâmetro cujo valor não seja constante é dinâmico.<br><br><br>Isso inclui parâmetros expostos, quaisquer parâmetros afetados por um parâmetro exposto e qualquer valor de parâmetro afetado pela [amostragem em uma textura](#texture-sampling).<br><br>Ao contrário dos [parâmetros estáticos](#static-parameter), o valor dos parâmetros dinâmicos pode ser ajustado instantaneamente após a compilação do gráfico em um [arquivo SBSAR](#sbsar-file). |

## E

|                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="evaluation" data-preserve-html="true"></span>Avaliação</b> | O processo de resolver a propagação de dados e parâmetros no gráfico. A avaliação verifica a validade de um gráfico e suas conexões, aplica [herança](#inheritance) e [cozinha](#cooking) o gráfico.<br><br>Na Exibição de Gráfico, uma conexão é representada com uma linha pontilhada quando não é avaliada.<br>A avaliação transforma a conexão em linhas sólidas.<br><br><br>Sempre que um parâmetro é ajustado em um gráfico, o nó que hospeda esse parâmetro e todos os nós downstream são [invalidados](#invalidation) e precisam ser reavaliados antes de serem [renderizados](#rendering). |

|                                                                         |                                                                                                                                  |
|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="filter" data-preserve-html="true"></span>Filtro</b> (Nó) | Um [nó](#node) que aplica uma modificação a uma imagem (por exemplo, uma deformação) ou extrai informações dela (por exemplo, uma máscara). |

## G

|                                                                                            |                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="ghost-instance-node" data-preserve-html="true"></span>Nó de instância fantasma</b> | Um [nó de instância](#instance-node) que faz referência a um [subgrafo](#subgraph) não encontrado, ou seja, uma [dependência](#dependency) ausente, foi carregado como um nó de instância fantasma.<br><br>Os nós de instância fantasma são restaurados para o estado esperado resolvendo a dependência ausente e recarregando o [pacote](#package). |
| <b><span id="glossiness" data-preserve-html="true"></span>Textura reluzente</b> | Um canal de um [material](#material) definido usando o modelo de Textura reluzente do Specular PBR [sombreamento](#shader). A textura reluzente especifica a rugosidade de uma superfície, isto é, variações microscópicas de height, também chamadas de *microfacetas*.<br><br>A alta luminosidade resulta em uma aparência suave, enquanto a baixa luminosidade resulta em uma aparência áspera e fosca.<br><br>É o inverso da [aspereza](#roughness). |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="histogram" data-preserve-html="true"></span>Histograma (imagem)</b> | No contexto de uma imagem, um histograma representa a população dos valores em um determinado intervalo, geralmente [0, 1].<br><br>Essa população é visualizada usando barras verticais, em que um valor mais presente na imagem resulta em uma barra mais alta para esse valor.<br>As barras são distribuídas horizontalmente de valores baixos (escuros) a valores altos (brilhantes).<br><br>Histogramas de imagens coloridas geralmente se sobrepõem aos histogramas de cada um de seus canais, geralmente R, G, B. |

## I

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="inheritance" data-preserve-html="true"></span>Herança</b> | No contexto dos gráficos de Substance, a herança descreve a propriedade dos nós que adquirem valores de parâmetro de seus nós upstream ou seu gráfico pai.<br><br>Os parâmetros herdados incluem [resolução](#resolution) ([tamanho de saída](#output-size)), [profundidade de bits](#bit-depth) ([formato de saída](#output-format)) e o modo [lado a lado](#tiling).<br><br>Saiba mais sobre herança nesta [página dedicada](../compositing-graphs/inheritance-compositing/inheritance-in-substance-compositing-graphs.md). |
| <b><span id="instance-node" data-preserve-html="true"></span>Nó de instância</b> | Um nó de instância representa um gráfico A em outro gráfico B. Nesse caso, o gráfico A pode ser chamado de [subgrafo](#subgraph) do gráfico B. Qualquer alteração no gráfico A é propagada para todos os nós de instância que a representam.<br><br>O nó da instância aplica seu próprio conjunto de valores para os parâmetros de entrada do gráfico A no contexto do gráfico B. Nesse sentido, o gráfico B pode hospedar vários nós de instância que fazem referência ao gráfico A, mas cada um passa valores ou texturas diferentes como entradas no gráfico A.<br><br>Todos os nós na Biblioteca do Designer que não são [nós atômicos](#atomic-node) são nós de instância. |
| <b><span id="invalidation" data-preserve-html="true"></span>Invalidação</b> | O processo que declara que o resultado de um nó está desatualizado.<br><br>Quando um parâmetro é ajustado, o nó que hospeda esse parâmetro e todos os nós downstream são invalidados, portanto precisam ser [avaliados](#evaluation) e [renderizados](#rendering) novamente. |

## M

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="material" data-preserve-html="true"></span>Material</b> | A coleção de propriedades e comportamentos da matéria no espaço, que inclui superfícies e volumes.<br>A aparência de uma entidade no espaço 3D é definida por seu material.<br><br>Os materiais podem ser definidos de várias maneiras, e nem todas as definições oferecem suporte a todas as propriedades, como refração, anisotropia ou brilho. Um [sombreador](#shader) é uma implementação específica de uma definição de material.<br><br><b>Importante:</b> o termo &#39;material&#39; é um *termo geral* usado para se referir a várias coisas, incluindo:<ul data-preserve-html="true"> <li data-preserve-html="true">O [sombreador](#shader) usado para calcular a aparência de uma superfície ou volume;</li> <li data-preserve-html="true">O conjunto de [texturas](#texture) fornecido para um sombreador;</li> <li data-preserve-html="true">Uma ID de material, que é um atributo de uma primitiva 3D usada para distinguir as partes que usam materiais diferentes.</li> </ul> |
| <b><span id="mesh" data-preserve-html="true"></span>Malha</b> | Um objeto 3D composto de [vértices](#vertex) conectados por bordas para formar polígonos, como triângulos, que por sua vez são montados em superfícies. Estas superfícies podem ser abertas ou fechadas.<br><br>A aparência dessas superfícies é definida pelo [material](#material) atribuído a elas.<br>O nível de detalhe de uma malha também é altamente dependente de seu [policount](#polycount). |
| <b><span id="metadata" data-preserve-html="true"></span>Metadados</b> | Dados que fornecem informações sobre o próprio arquivo, seu ambiente ou qualquer coisa relacionada aos dados do arquivo.<br><br>Os metadados comuns incluem o autor do arquivo, as datas de criação e modificação, os direitos autorais e a arte da capa.<br><br>No Designer, o conteúdo de um [pacote](#package) também pode ter metadados. Por exemplo, um gráfico de Substance que gera um material de estrutura pode ter metadados para as propriedades físicas da estrutura. |
| <b><span id="mipmap" data-preserve-html="true"></span>Mipmap</b> | Uma versão menor de uma [textura](#texture), geralmente calculada automaticamente.<br><br>Uma textura pode ter uma pirâmide de versões menores de si mesma, que são intercambiáveis no tempo de execução, de modo que o tamanho mais apropriado seja usado para obter a qualidade e o desempenho ideais.<br><br>Por exemplo, uma textura com detalhes de alta frequência exibidos em um tamanho menor provavelmente produzirá artefatos *moiré*. Além disso, uma textura maior provavelmente envolve mais [amostras de textura](#texture-sampling).<br><br>O termo &#39;mipmap&#39; se origina da técnica de mapeamento MIP, onde MIP significa &#39;*multum in parvo*&#39; latino, que significa &#39;muitas coisas em um lugar pequeno&#39;. |

## N

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="node" data-preserve-html="true"></span>Nó</b> | Objeto em um gráfico que executa cálculos e gera um ou mais resultados.<br><br>O resultado é controlado usando parâmetros de entrada. Esses parâmetros podem ser listados como controles no Dock Propriedades ou como conectores de entrada no próprio nó.<br><br>Há duas categorias principais de nós: [nós atômicos](#atomic-node) e [nós de instância](#instance-node). |
| <b><span id="noise" data-preserve-html="true"></span>Ruído</b> | Uma imagem não figurativa que representa uma distribuição aleatória ou pseudoaleatória de formas e cores. Os ruídos costumam ser usados para adicionar variação a superfícies ou deformações.<br><br>A biblioteca de nós do Designer inclui uma grande coleção de geradores de ruído, como [Manchas de Pb](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/bnw-spots-2/bnw-spots-2.md), [Nuvens](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/clouds-2/clouds-2.md), [Ruído de execução](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/perlin-noise/perlin-noise.md) ou [Voronoi](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/voronoi/voronoi.md). |
| <b><span id="normal" data-preserve-html="true"></span>Normal</b> | Na computação 3D, o normal de uma superfície é um vetor [normalizado](#normalization) perpendicular a essa superfície, saindo dessa superfície para fora.<br><br>Este vetor representa a orientação de uma superfície no espaço 3D e é usado para [sombreamento](#shader) que superfície de acordo com as luzes da cena e a perspectiva da câmera.<br><br>Uma textura de [mapa normal](#normal-map) pode ser aplicada a uma superfície para modificar suas normais e adicionar detalhes. |
| <b><span id="normal-map" data-preserve-html="true"></span>Mapa normal</b> | Uma [textura](#texture) aplicada em uma superfície para modificar seus normais.<br><br>É usado com mais frequência para simular detalhes que seriam ineficientes de incluir na geometria de um modelo. O uso desse mapa permite ter normais por-[texel](#texel) além dos normais por-[vértice](#vertex), resultando em mais informações sobre a superfície e, portanto, mais detalhes sobre a superfície.<br><br>As coordenadas X, Y e Z dos vetores normais são codificadas nos canais vermelho, verde e azul do mapa, respectivamente. Dependendo da API gráfica de destino ([DirectX](#directx) ou [OpenGL](#opengl)), o canal verde pode ser invertido. |
| <b><span id="normalization" data-preserve-html="true"></span>Normalização</b> | O processo de remapeamento de um intervalo de valores para o intervalo [0, 1], no qual o maior valor de entrada é remapeado para 1,0 e o menor valor de entrada é remapeado para 0,0.<br><br>Para vetores, a normalização é o ajuste do comprimento do vetor (ou &#39;magnitude&#39;) para um valor de 1,0. |
